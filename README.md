# Executive Summary — Finance Report (Power BI)

**Learning project** — built in Power BI Desktop from Microsoft's Financial Sample dataset, as hands-on practice while preparing for the PL-300 (Power BI Data Analyst) certification.

## What's in it
- **Model:** `financials` fact table (Sales, COGS, Profit, Discounts, Gross Sales, Manufacturing Price, Country, Product, Segment, Date…) linked to a `Calendar` date table
- **Report page:** Executive Summary with profit trend by year/month, profit by country (map visual), sales by product and segment, and Year/Month slicers

## Skills practiced
- Data modeling: fact table + date table, many-to-one relationship, marking a date table
- Power Query: data types, basic cleaning
- Report building: line charts, maps, bar charts, slicers, KPI-style layout
